## Overview

This chapter focuses on investigating the Windows operating system — file systems, registry, event logs, and artifacts that reveal user and system activity.

---

## Key Topics

- Windows file systems (NTFS/FAT) and structures
- The Windows Registry as a forensic artifact
- Event logs and their forensic value
- Prefetch, jump lists, and recent file artifacts
- User account and login activity analysis
- Memory (RAM) forensics on Windows systems
