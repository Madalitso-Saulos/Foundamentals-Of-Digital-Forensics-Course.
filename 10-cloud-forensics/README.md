## Overview

Cloud forensics focuses on collecting and analyzing evidence stored in cloud environments, including cloud storage, applications, virtual machines, and user activity.

---

## Key Topics

- Cloud service and deployment models (IaaS, PaaS, SaaS)
- Challenges unique to cloud forensics (multi-tenancy, jurisdiction)
- Acquiring evidence from cloud providers
- Investigating cloud storage and collaboration platforms
- Virtual machine and container forensics
- Working with cloud provider logs and APIs
