## Overview

Network forensics involves monitoring and analyzing network traffic to identify security incidents. This chapter covers techniques for detecting cyberattacks, unauthorized access, and reconstructing communications.

---

## Key Topics

- Fundamentals of network traffic analysis
- Packet capture and analysis (e.g. Wireshark)
- Log analysis: firewalls, IDS/IPS, routers
- Detecting intrusions and lateral movement
- Reconstructing sessions and file transfers
- Challenges in network forensics (encryption, volume of data)
