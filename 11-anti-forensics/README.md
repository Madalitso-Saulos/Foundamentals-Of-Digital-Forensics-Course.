## Overview

Anti-forensics covers the techniques attackers use to hide, destroy, or manipulate evidence, and how investigators detect and counter these methods.

---

## Key Topics

- Data hiding techniques (steganography, alternate data streams)
- Data wiping and secure deletion
- Encryption as an anti-forensic barrier
- Log tampering and timestamp manipulation
- Detecting anti-forensic activity
- Countermeasures and best practices
